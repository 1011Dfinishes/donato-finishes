# Donato Plumbing – Plumbing Finishes

Photo documentation app for plumbing finishes, Units 1–16.

- Anyone with the link can view, live.
- Approved editors (the `editors` table in Supabase) can add photos and sign.
- Every photo is cropped to fill its box and stamped with the date, time and **1011 1 AVE**.
- Each unit exports to a PDF in the Donato photo book layout.

Hosted with GitHub Pages; data and photos are stored in Supabase.
